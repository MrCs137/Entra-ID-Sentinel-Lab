## Overview

Hands-on lab securing a Microsoft Entra ID tenant end to end: enforcing strong authentication, restricting access with Conditional Access, governing privileged roles with Privileged Identity Management (PIM), reviewing access, and investigating activity in Microsoft Sentinel.

**Why it matters:** These are the core controls an IAM or SOC analyst works with daily. They map directly to the NIST SP 800-53 **Access Control (AC)** and **Identification & Authentication (IA)** families and to zero-trust principles.

## What I Did

- [x] Enforced multi-factor authentication (MFA)
- [x] Built Conditional Access policies
- [x] Configured PIM for just-in-time privileged access
- [x] Ran access reviews
- [x] Investigated activity in Microsoft Sentinel
